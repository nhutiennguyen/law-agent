# Thư mục Dữ liệu Pháp luật (data/)

Thư mục này dùng để lưu trữ các văn bản pháp luật, hợp đồng mẫu và dữ liệu phục vụ cho tính năng RAG trong tương lai.

## Cấu trúc:
- `raw_laws/`: Chứa các file văn bản luật nguyên bản dạng `.md` hoặc `.txt` (ví dụ: `bo_luat_lao_dong_2019.md`, `bo_luat_dan_su_2015.md`).
- `embeddings/`: (Dành cho Phase 3) Lưu trữ vector embeddings được sinh ra bởi ChromaDB hoặc mô hình embedding.
